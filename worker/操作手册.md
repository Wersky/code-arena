## 四条命令

```powershell
cd D:\zcode-work\godot\projects\prompt-arena
tools\export_web.bat
cd worker
wrangler deploy
```

第一次用要设 secret（只做一次）：

```powershell
cd D:\zcode-work\godot\projects\prompt-arena\worker
wrangler secret put ACCESS_CODE        # 你自己定一个访问码
wrangler secret put SESSION_SECRET     # 随便一串随机字符
wrangler secret put LLM_BASE           # https://api.commandcode.ai/provider/v1
wrangler secret put LLM_KEY            # 你的 commandcode key
wrangler secret put IMG_BASE           # https://kuaipao.pro
wrangler secret put IMG_KEY            # 你的 kuaipao key
```

## 验证（关键 3 条）

```powershell
$U = "https://code-arena-gate.你的账号.workers.dev"

# 1. 匿名下 pck → 必须 403
curl -s -o NUL -w "%{http_code}`n" "$U/game.pck"

# 2. 匿名下分片 → 必须 403（这条最容易漏，漏了就等于没门禁）
curl -s -o NUL -w "%{http_code}`n" "$U/game-part1.pck"

# 3. 匿名调代理 → 必须 401
curl -s -o NUL -w "%{http_code}`n" -X POST "$U/proxy/llm/v1/chat/completions"
```

浏览器打开 `$U` → 输访问码 → 看到终端雨 +「初始化」→ 点进去 → 侧栏「模型接入」→ 点「测试连接」应显示连接成功。

## 改码 / 撤权

```powershell
cd worker
wrangler secret put ACCESS_CODE     # 换新码，上传即生效（实测 2026-11-23：无需再 deploy）
wrangler secret put SESSION_SECRET  # 换这个=让所有人现有 Cookie 立即失效
wrangler deploy                     # 仅当改了 src/ 或 wrangler.toml 才需要
```

## 出问题看哪

| 现象 | 查这里 |
|---|---|
| `Asset too large` | 没跑 `tools\export_web.bat`（它会把原始 pck 从部署目录排除） |
| 打开 503 | `wrangler.toml` 缺 `binding = "ASSETS"` |
| 匿名能下分片 | `run_worker_first` 不是 `true` |
| 加载卡 0% | `worker/public/` 里有没有 `game-part1.pck` / `game-part2.pck` |
| AI 报错 | F12 Console 红字；或看 README 的「4 个 bug」表 |
