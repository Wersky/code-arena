# 梗卡插画清单（art-meme）

> 界面层（ui-meme）按本表把卡 id 映射到贴图文件。**文件名必须一字不差。**
>
> 目录：`res://assets/art/`
> 尺寸：**150 × 226 px**（与卡背 `CardView.CARD_SIZE` 完全一致，1:1 直接贴，不缩放不糊）
> 像素网格：75 × 113 → 最近邻 ×2
> 调色板：限定 32 色（MEDIANCUT，无抖动，硬边色块）
> 颜色模式：RGB（**不透明**，满幅铺满卡背，四边无留白/无透明缝）
> 风格：16-bit 像素风（硬边、无抗锯齿、阶梯色阶、剪影优先）
> 文字：**图里没有任何文字**。卡面文字由界面层用 Ark Pixel 字体（`font.mode="1"` 1bit 位图渲染）在像素网格上合成。
