## 0. 三十秒看懂

**一款 Godot 2D 肉鸽卡牌游戏。** 玩家选一位 AI 娘，她会被画在**每张牌的中间**；
把牌凑成**德州扑克牌型**打出去，`筹码 × 倍率` 就是这一手的分数。过 10 关。

- 纯鼠标操作，没有横版动作
- 牌面：白纸 + 四角花色点数 + 中间角色（不做满幅插画）
- 花色决定效果：**红牌（♥♦）每张 +3 倍率，黑牌（♠♣）每张 +25 筹码**
- 四个花色的角色形象各不相同，但都属于同一批 AI 娘

## 4. 工具链

所有生成/处理脚本都在 `tools/`，**不要另起炉灶**：

| 脚本 | 作用 |
|---|---|
| `make_card_assets.py` | **样张 → 游戏卡面资产**：÷4 无损下采样、按形状抠角色、拆出角标层。`--suit <spade> --check-only` 可只校验 |
| `gen_rank_arts.py` | **按点数生成卡面角色**（手势/抱字母），`--suit --sheet --look --out` |
| `make_pips.py` | 点数角标：像素字体放大 15 倍 |
| `compose_card_preview.py` | **把角色图合成成卡**：白底 + 四角角标 + 圆角透明 + 严格居中 |
| `gen_poker_cards.py` | 早期 16 张「AI娘×花色」满幅卡图（旧，存档） |
| `pixelize_poker_cards.py` | 原图 → 75×113 网格量化 32 色 → 最近邻 ×2 = 150×226 |
| `balance_sim2.gd` | 扑克玩法平衡模拟（枚举 31 个子集取最优） |
| `analyze_targets.py` | 离线反推目标分（读 `--dump` 的得分矩阵） |

### 出图约定（**踩过坑，照做**）

```bash
# 1) 先出「三视图 + 正面细节」当身份锚（16:9、白底）
python pictures/gen.py --name <sheet> --style pixel-art --model gpt-image-2.5-1k --ar 16:9 \
  --ref <角色参考图> --subject "..." --action "three views + close-up" ...
# 2) 再用这张三视图当 --ref，批量出 12 个点数
python tools/gen_rank_arts.py --suit <suit> --sheet <sheet.png> --look "..." --out <suit>
# 3) 最后合成
python tools/compose_card_preview.py --src <角色图> --suit <suit> --rank <n> --pip auto --out <out>
```

- **模型用 `gpt-image-2.5-1k`**：2k 会撞网关 145 秒硬超时；1k 稳定约 35 秒
- **一次只发 2 个并发**：再多容易 429
- **两张参考图容易 504**：能只用一张就只用一张
- 出图脚本有**新鲜度校验**：只认本次请求之后生成的文件，避免拿旧图冒充结果
