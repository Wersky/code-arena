### ⛔ 别直接进商业版的（常见坑）
- **BBC Sound Effects**（RemArc 许可）：个人/教育/研究，**不能用于商业游戏**。
- **YouTube Audio Library**：面向 YouTube 创作者，Steam/主机发行规则不同。
- **Unity Asset Store 免费音频**：受 Unity EULA 约束，别搬进 Godot 项目。
- Freesound 里 `CC-BY-NC`：**"免费下载"≠"可以卖"**。
- `CC-BY-SA` / `GPL` 音频：要求衍生作品同协议，闭源商业项目基本无解。

## 2. 生成器（无许可问题，和现有合成音互补）

| 工具 | 链接 | 说明 |
|---|---|---|
| **Bfxr** | bfxr.net | 浏览器，sfxr 血统，Pickup/Laser/Explosion/Hit 预设，导出 WAV |
| **jsfxr** | sfxr.me | 更快，10 秒一个，输出归你所有 |

| **rFXGen** | raylib 作者作品 | 桌面版，波形可视化 + 批量导出 |
| **LabChirp** | Windows | 多通道叠加，能做出"不像机生成"的层叠音 |

> 现在项目里 `SfxNode` 就是**程序合成**（`scripts/core/sfx.gd` 生成 WAV），
> 生成器适合补"要更厚/更脆"的具体音；素材库适合补"真实质感"（卡牌摩擦、纸张、金属）。

## 3. 落地流程（照做）

1. **先列清单再下载**：从游戏事件反推音效名（见下节映射表），别边逛边下。
2. **下载落 D 盘**：`D:\workbuddy-data\audio\<来源>\<包名>\`；入库前只把选中的拷进
   `assets/audio/sfx/`（Godot 只认用到的文件）。
3. **格式**：音效用 **WAV 16bit/44.1k**（≤0.5s 的短音，避免 OGG 起播延迟）；
   BGM 用 **OGG/MP3** 循环。截掉开头静音（减少触发延迟）。
4. **音量归一**：全部 normalize 到 −1 dBFS，再在游戏总线里统一压（现有 Music −20dB / SFX −13dB）。
5. **留档**：每批素材在 `assets/audio/LICENSES.md` 记一行：`文件名 | 来源 URL | 许可 | 作者 | 下载日期`；
   下载时的许可页截图存同目录。**这一步能救命**——上线前审核就看它。
6. **Godot 导入**：WAV 勾 Loop=Off（音效）；BGM 勾 Loop=Forward；
   `SFX` 总线加 Limiter 防叠加爆音。

## 5. 一句话决策

- **要零法律风险、快速铺满**：Kenney（CC0）+ jsfxr/ChipTone（自生成）。
- **要真实质感**（卡牌、纸张、金属、冲击）：Sonniss GDC + Freesound（只取 CC0）。
- **要具体某一个音**：Freesound 搜（CC0 过滤）→ 不行再 FindSounds 捞。
- **想省事先用现成**：项目现有合成音已经能用，替换时按上表一个 key 一个 key 换，别整体替换。
