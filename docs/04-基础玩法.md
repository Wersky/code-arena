## 0. 一句话

**选一位 AI 娘，她会被画在你每一张牌的中间。
把牌凑成德州牌型打出去，`筹码 × 倍率` 就是这一手的分数。**

---

## 1. 为什么换成扑克

代码卡玩法要求玩家先学会三条语法规则才敢出牌（`while` 要和 `if` 配对、
顺序错了只给 1 分）——**门槛在学习规则，不在做决策**。

扑克牌型是**玩家已经会了的语言**：一对、三条、同花、顺子，不用教。
玩家一上手就在做决策：这手牌该凑对子还是赌同花？

代码卡**没有删**，`code_cards.gd` / `code_program.gd` 留在仓库里，
以后可以作为"特殊道具卡"加回来。

## 2. 牌

### 2.1 牌面结构

```
┌────────────────┐
│ ♥ 3            │  ← 左上角：花色符号 + 点数
│                │
│    [ AI 娘 ]   │  ← 中间：玩家选的 AI 娘（按花色换主题配色）
│                │
│          3 ♥   │  ← 右下角倒排
├────────────────┤
│ 点数 3  +3 倍率 │  ← 底条：点数 + 这张牌给什么
└────────────────┘
```

- **花色决定效果**（整个玩法最简单的一条规则）：
  - **红（♥ 红心 / ♦ 方块）**：每张 **+3 倍率**
  - **黑（♠ 黑桃 / ♣ 梅花）**：每张 **+25 筹码**
- **点数**（1~10）：直接加进筹码池。
- **AI 娘**：4 位 AI 娘 × 4 种花色 = 16 张卡图，`assets/art/poker-<ai>-<suit>.png`。
  卡图是满幅像素画，配色随花色变（红心=玫红、方块=橙红、黑桃=冷蓝、梅花=墨绿）。

### 2.2 起始牌库（9 张）

```
♥1  ♥3  ♥5  ♦2  ♦4  ♠3  ♠6  ♣1  ♣4
```

- 点数重复（1/3/4 各两张）→ **起手就能凑一对**
- 四种花色都有 → 后面加牌可以追同花
- 点数 1~5 连续 → 理论上能凑顺子

### 2.3 成长

过关后三选一：**往牌库里加一张牌**（随机花色 + 点数 1~10）。
牌库变大 → 高牌型（三条/四条/同花）才凑得出来。

## 3. 牌型（德州扑克）

| 牌型 | 筹码 | 倍率 |
|---|---|---|
| 高牌 | 5 | 1 |
| 一对 | 10 | 2 |
| 两对 | 20 | 2 |
| 三条 | 30 | 3 |
| 顺子 | 30 | 4 |
| 同花 | 35 | 4 |
| 葫芦 | 40 | 4 |
| 四条 | 60 | 7 |
| 同花顺 | 100 | 8 |
| 五条（同点数 ×5） | 120 | 12 |

选 1~5 张，取**能组成的最高牌型**。单张 = 高牌。

## 4. 计分

```
筹码 = 牌型筹码 + Σ 点数 + 黑牌数 × 25 + AI娘筹码加成 + 永久加成
倍率 = 牌型倍率 + 红牌数 × 3  + AI娘倍率加成 + 永久加成
得分 = 筹码 × 倍率
```

**手算示例**：♥3 + ♦3（一对，两张红牌，DeepDeek）
```
筹码 = 10（一对）+ 3 + 3 = 16
倍率 = 2（一对）+ 3 + 3（两张红牌）+ 2（DeepDeek 红心 +2）= 10
得分 = 160
```

命令行下方**实时显示**：`一对 ｜ 16 筹码 × 10 倍率 = 160`。

## 6. 一局流程

```
主菜单 → 选 AI 娘 → L1
  ↓
选牌（最多 5 张，点一下抬起、再点取消）
  ↓
运行 → 筹码 × 倍率 → 加分
  ↓
补满手牌，出牌次数 −1
  ↓
出牌次数用完 → 分数 ≥ 目标? → 过关 → 加一张牌 → 下一关
```

- 每关 **2 次弃牌**：把选中的牌扔掉、补新的（不计分、不扣出牌次数）。
- 一关 3~7 次出牌，目标分 2050~5220。

| 关 | 名称 | 目标分 | 出牌 |
|---|---|---|---|
| L1 | 起手 | 2050 | 3 |
| L2 | 凑一对 | 2100 | 3 |
| L3 | 凑两对 | 2850 | 4 |
| L4 | 三条 | 2950 | 4 |
| L5 | 顺子 | 3650 | 5 |
| L6 | 同花 | 3700 | 5 |
| L7 | 葫芦 | 4450 | 6 |
| L8 | 四条 | 4550 | 6 |
| L9 | 同花顺 | 5200 | 7 |
| L10 | 终局 | 5220 | 7 |
